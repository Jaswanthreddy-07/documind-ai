# DocuMind AI — Chat with Your Documents

DocuMind AI is a local Retrieval-Augmented Generation (RAG) application that lets a user upload text-based PDFs, ask questions, and receive answers grounded in retrieved passages with source-page citations.

## Features

- Upload one or more PDFs
- Extract text with 1-based page metadata using PyMuPDF
- Split pages into overlapping chunks
- Semantic retrieval with `sentence-transformers/all-MiniLM-L6-v2` and cosine similarity
- Answer generation with a local Ollama model
- Source/page citations and an evidence-inspection panel
- Tests for chunking and metadata preservation
- No paid model API or cloud account required

## Architecture

`PDF upload → text extraction → chunking → embeddings → top-k retrieval → local LLM → answer with citations`

## Requirements

- Windows 10/11 (instructions below), macOS, or Linux
- Python 3.11 recommended
- 8 GB RAM minimum; 16 GB is preferable for a local model
- Internet for initial package/model downloads
- Ollama installed and a local model downloaded

## Setup on Windows

Open PowerShell in the folder where you want the project.

1. Create and enter the project folder (or unzip this repository first):

   ```powershell
   cd documind-ai
   ```

2. Create a virtual environment:

   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt and run `.venv\Scripts\activate.bat`, or continue using `.venv\Scripts\python.exe -m pip`.

3. Upgrade pip and install dependencies:

   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. Install Ollama from https://ollama.com/download/windows and open the application.

5. Download a small local model:

   ```powershell
   ollama pull llama3.2:3b
   ```

   Test it:

   ```powershell
   ollama run llama3.2:3b
   ```

   Ask a short question, then type `/bye` to exit. Keep Ollama running in the background while using DocuMind AI.

6. Start the app from the project directory:

   ```powershell
   streamlit run app.py
   ```

7. Streamlit will open a local browser page. Upload a text-based PDF and ask a question.

The first run also downloads the embedding model from Hugging Face. Allow time and disk space for the initial downloads.

## Run tests

```powershell
pytest -q
```

## Evaluation plan

Create a small set of questions whose answers are known from your PDFs. Track:

- **Retrieval Recall@k:** whether a relevant page/chunk appears in the top k retrieved results
- **Answer correctness:** whether the answer matches the source evidence
- **Citation accuracy:** whether cited sources and page numbers support the claim
- **Abstention quality:** whether the app admits when the PDFs do not contain the answer
- **Latency:** time to retrieve and generate an answer

Do not publish performance numbers until you have run the evaluation. A useful first evaluation set is 30–50 questions: direct facts, paraphrased questions, multi-page questions, and questions not answerable from the PDF.

## Limitations

- Scanned/image-only PDFs are not OCR-processed in this version.
- The local LLM may be slow on CPU-only hardware.
- Similarity scores are ranking signals, not probabilities of correctness.
- Citations are generated by the LLM and must be checked against the evidence panel.
- Long documents and tables may require better chunking or OCR.
- Do not treat generated answers as authoritative without checking the original document.

## Suggested next improvements

1. Add OCR for scanned PDFs.
2. Add a configurable similarity threshold and stronger abstention behavior.
3. Add an evaluation script and record measured results.
4. Add chat history and document deletion controls.
5. Deploy only after considering document privacy and hosting constraints.
